# CLAUDE.md

tab is the library: `tab.lua`, `tab-eg.lua`, and the `,/` scripts that
run them. Keep it that way.

Everything else belongs in `../tab-dev`, the sibling repo: experiment
results, score csvs, figures, sweeps, scratch files, and the notes on
what has been tried. Write them there, not here.

Read `../tab-dev/CLAUDE.md` before proposing an experiment. It lists
what has already been measured and rejected.
